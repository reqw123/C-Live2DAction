# Game Design Document — Live2DAction (Draft)

## 核心玩法

固定場景第三人稱 3D 動作戰鬥，關卡制（非開放世界）。移動、普攻連段、主動技能、閃避、鎖定敵人，卡通渲染，強調打擊感（Hit Stop、擊退、受擊反應、相機震動接口）。

## 玩家循環

```
啟動畫面 → 主選單 → 劇情／Live2D 對話 → 角色或關卡選擇
→ 載入固定 3D 戰鬥場景 → 擊敗敵人與 Boss → 關卡結算
→ 解鎖劇情或能力 → 返回關卡選擇
```

## 操作方式

- WASD：相對攝影機方向移動
- 滑鼠：攝影機旋轉
- 滑鼠左鍵：三段連段普攻（Attack1 → Attack2 → Attack3，有連段窗口）
- 技能鍵（E）：主動技能，冷卻限制
- 閃避鍵：方向閃避，有明確無敵幀
- 鎖定鍵：鎖定/切換敵人
- 跳躍鍵（空白鍵）：貼地才能觸發，無雙跳/連續跳

**2026-08-11 更新**：垂直切片版本原本不含跳躍，這天使用者確認納入範圍——加入基本跳躍（貼地觸發、無雙跳），暫不含跳躍動畫與空中攻擊/連段等延伸機制，那些仍視為範圍外，之後如有需要再另外討論。

## 戰鬥規則

資料驅動（`AttackData`/`SkillData` ScriptableObject），每個攻擊含 AttackId、Animation、Damage、Startup/Active/Recovery、Hitbox 形狀與位移、Knockback、HitStun、連段窗口、可否被打斷、VFX/SFX/相機衝擊/HitStop。傷害流程：`AttackDefinition → HitDetection → DamageInfo → IDamageable → Health → HitReaction → VFX/SFX/HitStop`。同一次攻擊不重複傷害同一目標。

## 角色能力（垂直切片）

1 名可操作角色：三段普攻、1 個主動技能、1 個閃避（含無敵幀，冷卻限制）。

## 敵人種類（垂直切片）

- 近戰普通敵人：接近玩家、進入距離後近戰攻擊。
- 遠程普通敵人：保持距離、發射物件池管理的投射物。

狀態機：Idle → Detect → Chase → Strafe → Attack → Cooldown → Hurt → Stagger → Dead。

## Boss 設計（垂直切片，簡化版）

登場 → 第一階段 → 攻擊模式循環 → 低血量變化 → 死亡 → 勝利結算。至少一個近距離攻擊、一個範圍攻擊，攻擊需有清楚預警、可被閃避、有血條、死亡演出。

## 關卡流程

單一固定 3D 戰鬥場景（垂直切片），敵人與 Boss 依序或依觸發條件出現，擊敗全部後進入結算。

## 勝利與失敗條件

- 勝利：清除場上所有敵人與 Boss。
- 失敗：玩家血量歸零，死亡後停止控制，顯示失敗畫面，可重新開始或返回主選單。

## Live2D 劇情流程

短篇開場對話（角色介紹/情境鋪陳）→ 進入 3D 戰鬥 → 戰鬥結束 → 短篇結束對話 → 返回主選單。對話系統支援角色名稱、對話文字、Live2D 立繪、表情切換、Motion 觸發、下一句、跳過、結束事件。

**目前使用的 076/077 Live2D 模型僅為內部原型佔位，不代表正式角色設計，見 `ASSET_LICENSES.md`。正式角色、世界觀、劇情文字待原創設計定案。**

## 上市版本範圍（垂直切片之後）

1 名完整可操作角色、3 個固定戰鬥場景、3 種普通敵人、2 個 Boss、三段普攻、2 個主動技能、1 個終極技能、閃避與無敵幀、角色成長/技能強化、完整主選單、關卡選擇、設定介面、存檔、教學、Live2D 劇情演出（原創角色）、中文介面、英文介面架構、30～90 分鐘遊戲內容、Windows 正式 Build。

## 明確不做的功能（垂直切片與 Alpha/Beta 未穩定前）

開放世界、多人連線、抽卡、四人隊伍切換、攀爬、游泳、滑翔、大型城鎮、大量 NPC 日程、程序生成世界、超過 1 名可操作角色、手機/主機平台、複雜裝備系統、大量支線任務。

## 原創性聲明

角色、名稱、世界觀、服裝、武器造型、場景、圖示、音樂、音效、特效、UI、程式碼、商標一律原創，不複製《原神》或任何其他商業作品的受著作權保護素材。可參考的僅限玩法機制層面（移動手感、鎖定系統、連段結構等抽象設計模式），不涉及具體美術/文字/程式碼複製。
