# Test Plan (Draft — 隨 Phase 進度擴充)

## 測試分層

- **EditMode**：純資料/邏輯測試（傷害計算、狀態轉換、冷卻計時、命中判定去重）。
- **PlayMode**：跨影格流程測試（`[UnityTest]`，命中→扣血→UI、動畫轉場）。
- **手動驗證**：手感、視覺效果、攝影機行為——自動化測不出來的項目，必須在 Editor 內 Play 實測，不得以「理論上可行」代替。

## 垂直切片完成前的測試清單（隨 Phase 2 進度勾選）

- [ ] 角色可正常移動，不會穿過場景幾何。
- [ ] 攻擊每個目標只造成一次傷害。
- [ ] 三段連擊順序正確，連段窗口生效。
- [ ] 攻擊中斷規則正確（可否被打斷由資料控制）。
- [ ] 閃避無敵時間正確，冷卻限制生效。
- [ ] 技能冷卻正確，UI 顯示同步。
- [ ] 敵人死亡後不會繼續攻擊。
- [ ] 玩家死亡後輸入失效。
- [ ] Boss 死亡後只結算一次。
- [ ] 暫停時戰鬥停止。
- [ ] 重新開始能正確恢復狀態。
- [ ] 切換場景沒有 Missing Reference。
- [ ] Windows Build 可以啟動。

## Phase 1 灰盒原型的最小測試範圍

- [ ] 玩家移動方向與攝影機朝向一致（手動驗證）。
- [ ] 單次攻擊命中假人後扣血（EditMode + PlayMode）。
- [ ] 假人血量歸零後停止反應（EditMode）。
